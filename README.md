# Himja Infotech Clone

A front-end website recreation of **Himja Infotech**, built as a web development project using HTML, CSS, and JavaScript.

The project recreates a business website for a computer hardware and IT services company, including product information, computer repair services, surveillance systems, software services, customer testimonials, and contact information.

---

## 🌐 Project Overview

The **Himja Infotech Clone** is a front-end website project created to practice and demonstrate modern website development concepts such as:

* Website layout design
* Navigation systems
* Responsive UI development
* Multi-page website structure
* Service presentation
* Product presentation
* Image and asset management
* JavaScript interactions
* Customer testimonial carousel
* Reusable HTML/CSS components

The website is designed around the services and products of an IT and computer solutions company.

---

## 🎯 Project Objective

The main objective of this project was to recreate the structure and user experience of the Himja Infotech website while practicing front-end development.

The project focuses on creating a clean business website where users can:

* Explore computer products
* Learn about available services
* View surveillance/CCTV solutions
* Learn about software support
* Navigate between different sections
* View customer testimonials
* Find company contact information

## ⚙️ How to Run the Project

This is a static front-end website, so no backend server or database is required.

### Method 1 — Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

---

### Method 2 — Using VS Code

1. Download the repository.
2. Open the project folder in **Visual Studio Code**.
3. Install the **Live Server** extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. The website will open in your browser.

## 🚀 How to Use

After opening the website:

1. Start from the homepage.
2. Use the navigation bar to explore different sections.
3. Select **Products** to explore the product section.
4. Select **Surveillance Systems** to view CCTV-related information.
5. Select **Services** to explore available services.
6. Select **Contact Us** to view contact information.
7. Explore the customer testimonials section on the homepage.
